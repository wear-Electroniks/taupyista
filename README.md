# Ghulam Hussain — Data Science Portfolio Website

## Start
Open `index.html` in a modern browser. No build tools or server are required for normal viewing.

## Folder structure
- `index.html` — website content and project cards
- `assets/css/style.css` — appearance and responsive layout
- `assets/js/main.js` — mobile navigation, project filters, theme toggle, email copy
- `assets/images/` — portrait, favicon and illustrated project artwork

## Editing
1. Edit text, links, email, and sections in `index.html`.
2. Replace `assets/images/profile.jpg` with your own portrait (same filename) if desired.
3. For each project card, edit `data-categories` to update the filter behavior. Supported categories: `machine-learning`, `health-ai`, `genomics`.
4. Tweak colors via the CSS variables at the start of `style.css`.
5. A Google Fonts connection enhances typography; offline, system font fallbacks work.

Upload the entire folder to GitHub Pages, Netlify, or any static host. Set `index.html` as the entry page. No backend is required. The contact section uses mailto and a copy-email button, not a web form.
